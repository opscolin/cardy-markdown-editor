# Cardy UI 适配与响应式开发优化记录 (2026-05-26)

本文档记录了今日针对 **Cardy Markdown 编辑器** 在各种屏幕尺寸（宽屏桌面、手机端、iPad 各种横竖屏模式）下进行的 UI 修复与体验优化。

---

## 🛠️ 优化事项明细

### 1. 🖥️ 宽屏及中等屏幕 (1600px - 2600px) 头部菜单被挤压与隐藏优化
*   **问题现象**：在 1600px 至 2600px 宽度区间内，逐渐缩窄窗口时，页面顶部菜单右侧的按钮、导出操作区域会被挤出屏幕或隐藏显示不全。
*   **优化方案**：
    *   **动态控制标题宽度**：将顶部文件标题输入框的宽度从固定的 `w-64` 改为响应式 `w-44 xl:w-64`（并在获得焦点 `focus:` 时拉伸至 `w-64`），减少非核心状态的占比。
    *   **微调操作组间距**：自适应缩小了右侧动作面板在临界尺寸下的间隙（从 `gap-3 px-3` 调整为 `gap-2 min-[1400px]:gap-3`），避免了大屏下默认挤占过多空间。
    *   **隐藏次要辅助说明**：将“已自动保存”小灯泡标识设为仅在 `xl:` (1280px以上) 屏幕才显示，减少视觉噪音及横向排版压力。

### 2. 📱 移动端 (以 iPhone 12 Pro 为代表) 预览卡片顶部碰撞与内容遮挡修复
*   **问题现象**：手机端在预览分屏下，第一个卡片的顶部与屏幕顶部没有任何间隙，甚至被顶部导航栏严重遮挡，导致内容残缺。
*   **优化方案**：
    *   **添加安全内边距**：为预览容器（`Preview Pane`）统一添加了 `pt-10 px-4` 核心样式，给首张卡片留出优雅的用户视线缓冲纵深区。
    *   **修正卡片缩放边距（Transform Scale Margin Bug）**：移动端上小卡片会执行 `scale-[0.74] - scale-[0.84]` 的折叠渲染，原样式采用对称的负外边距 `my-[-65px]` 机制，容易造成顶部缩进塌陷。优化为 **`mt-0 mb-[负边界值]`** 的策略，彻底稳固了卡片顶部的零位计算，完美支持各种长度内容的滚动安全局域。

### 3. 📐 iPad Mini / Air / Pro 横竖屏自适应智能侧边栏 (Responsive Drawer Integration)
*   **优化诉求**：
    *   **竖屏 (Portrait)**：希望像手机端一样，侧边栏作为左侧浮层弹出（`Drawer` 模式），避免阻碍中等触屏设备的核心编辑或预览区域。
    *   **横屏 (Landscape)**：保留类似于桌面端的设计，侧边栏通过收放来直接改变剩余编辑工作区，支持双栏同屏的高效作业。
*   **完成重构**：
    *   **新增状态 `isDrawer`**：在代码根部引入了 `isDrawer` 精准判断逻辑，定义为：`屏幕宽度 < 768px || (屏幕宽度 <= 1024px 且 竖屏状态下)`。
    *   **动态绑定底层机制**：
        1.  侧边栏阴影遮罩（`Backdrop`）、侧边栏动画宽度 (`x: 0 / -280` vs `width: 280 / 0`) 均由原先单纯测算 `window.innerWidth < 768` 彻底重构为对 `isDrawer` 加载状态。
        2.  底部浮动切换栏（“编辑/预览”）和选项展开菜单也在 `isDrawer` 活动时才显示，而一旦转入大宽屏或 iPad 横屏则全显双栏、隐藏手机态底栏。
    *   **自适应防抖事件**：挂载全局 `resize` 事件。当用户旋转 iPad 或拉伸浏览器越过 1350px/iPad 临界值时，侧边栏可以自适应开启、合拢或调整状态，交互流畅、过渡自然。

## 📊 优化前后各视口对比

| 设备/尺寸 | 优化前表现 | 优化后表现 |
| :--- | :--- | :--- |
| **超宽屏桌面 (2K+)** | 控件间距过大，拉伸时偶有右侧顶栏掉卡现象 | 紧凑布局、极简排版、宽屏适配自如 |
| **iPad Pro/Air/Mini (横屏)** | 强制按台式机侧栏模式展示已有的 280px 文档单，没有空间分配冲突 | 完美无遮挡，双栏布局合理、编辑视窗透亮 |
| **iPad Pro/Air/Mini (竖屏)** | 原有代码作为 `md:flex` 强制展开侧栏，挤扁了中间的 Markdown 模块 | 自动隐藏为浮动式 `Drawer`抽屉。点击右上角菜单优雅滑出，点击空白处自动遮罩闭合 |
| **手机端 (iPhone/Android)** | 第一张幻灯片卡片顶部顶死，被操作栏半部分截断 | 给足 `pt-10` 头部留白，卡片居中度与视觉呼吸感体验极佳 |
