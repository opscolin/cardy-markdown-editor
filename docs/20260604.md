# Cardy Card-Based Markdown 导出功能升级记录 (2026-06-04)

本文档记录了今日针对 **Cardy Markdown 编辑器** 新增的“长图导出”核心功能的实现与交互优化。

---

## 🛠️ 优化与新增功能明细

### 1. 🖼️ 一键长图导出 (Long Image Export) 支持
*   **需求背景**：用户习惯在移动端、社交平台分享知识。单张卡片零散，PDF 传输繁重，需要一种能把所有卡片页垂直拼接为一幅精致长图的分享格式。
*   **实现方案**：
    *   **动态卡片渲染**：遍历所有被拆分出来的卡片组件，利用高性能 `html-to-image` 动画缓存导出单图 PNG。
    *   **智能化 Canvas 原生拼接**：计算所有卡片生成的原生高宽后，基于单张卡片尺寸对齐。通过高阶等比缩放规范逻辑，无缝支持横向上边距 (`paddingX`)、纵向上下保留边距 (`paddingY`)、卡片间精细社交呼吸感留白 (`gap`) 构建全套背景结构。
    *   **高精度输出**：导出的长图片分辨率高达 $2\times$ 视网膜清晰度（`pixelRatio: 2`），无论大小字重、段落代码框、内置图片，均极致丝滑。

### 2. 🎨 主题感知背景色自适应 (Theme-Aware Wallpaper Mode)
*   **优化细节**：导出的长图不再是粗暴的纯白或纯黑，而是智能感知当前应用主题：
    *   **亮色模式 (Light Mode)**：采用与官方预览背景一致的柔和优雅乳白微灰底色 (`#F9F9F7`)，使白色卡片自然漂浮、呼吸感强。
    *   **暗黑模式 (Dark Mode)**：采用质感高贵的深灰炭黑底色 (`#09090b`)，使精致的暗色卡片完美融合，带来富有专业视感的一体化渐变高级感。

### 3. 📱 跨端操作界面双路布局重构 (Responsive Button Panel Upgrade)
*   **桌面端侧**：顶部工具栏在 PDF 导出、ZIP 导出、Markdown 源码旁并列无缝置入首字母缩写长图 `ImageIcon` 悬浮组件，鼠标悬停时提供半透明“长图导出”极简微标签提示。
*   **移动/平板 Drawer 抽屉侧**：鉴于新加按钮破坏了移动端原有的 `grid-cols-3` 三段式底栏占比，将其精巧微调为 **`grid-cols-2` 2x2 网格卡片流布局**。视觉呼吸感更为平衡、点按目标更易聚焦，保障小至 $375px$ 以下手机的极致完美操作兼容。

## 📐 长图缝合数学参数规范

| 属性参数 | 指定值 (像素 px) | 用途与视觉意义 |
| :--- | :--- | :--- |
| **画布像素比 (`pixelRatio`)** | `2` (Ultra High Retina) | 解决低端设备导出图像发虚刺眼的问题 |
| **横向侧边内边距 (`paddingX`)** | `40 px` | 给予长图左右完美的物理侧边框感 |
| **纵向首尾内边距 (`paddingY`)
** | `40 px` | 保证拼图顶端与末尾不显得急促突兀 |
| **卡片纵向邻接间隙 (`gap`)** | `32 px` | 卡片与卡片之间优雅的黄金比例分割线 |
| **默认暗色画布填充 (`isDarkMode: true`)** | `#09090b` | 呈现高级的卡片悬浮于流延宇宙黑质感 |
| **默认亮色画布填充 (`isDarkMode: false`)** | `#F9F9F7` | 呈献雅致的小众美学手工磨砂米白纸质感 |
